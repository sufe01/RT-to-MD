How to use the editor

Open the editor

From formatted text to Markdown in seconds

No sign-up. Everything happens in your browser and nothing is uploaded to a server.

Quick start

  1. Write or paste. Click the white page and type, or paste from Google Docs, Word or a website.
  2. Format it. Use the toolbar at the top, or select some text and a small toolbar pops up beside it.
  3. Take it with you. Press Download and choose PDF, Word, Markdown, web page or plain text. Press Copy Markdown to copy only the Markdown.
Want to see the Markdown? Press Show Markdown. It appears next to your page and updates while you type.

Formatting text

Select the words first, then press a button:

Make a heading (big, medium, smaller). Press again to go back to normal text.
Bold, italic, underline, strikethrough.
Highlight text in yellow. Press again to remove it.
Make the selected text smaller or bigger.
Pick any text color or background color you like from the color picker.
Bullet list, numbered list, quote. Press Tab inside a list to indent an item, Shift+Tab to move it back.
Align the paragraph left, center, right, or justified.
Turn the selected text into a link. Leave the box empty to remove a link.
Remove formatting from the selection.

Tables

  1. Press and choose how many rows and columns you need.
  2. Click inside the table. A bar appears under it with + Row, + Column, − Row, − Column and Table (delete).
  3. The new row or column is added next to the cell where your cursor is.

Pictures

  1. Press , then paste a picture link, or choose Upload from device. You can also paste a screenshot straight into the page.
  2. Click a picture to select it. A bar appears above it where you can round the corners with the slider, set the size (25% to 100%), align it left, center or right, or delete it.

Fonts

  • Pick a font from the dropdown. With text selected it changes only that text. With nothing selected it changes the whole page.
  • Your own font: press Add my own font and choose a .ttf, .otf, .woff or .woff2 file. You can also type the name of a font installed on your computer into the font box and press Enter.

Code

  • turns selected text into inline code.
  • makes a code block with a Copy button in its corner. Click the button to copy the code.

Downloading

PDFLooks exactly like your page, including colors, fonts and pictures.
Word (.doc)Opens in Microsoft Word and Google Docs. Keeps colors, fonts and tables.
Markdown (.md)For GitHub, notes apps and blogs. Keeps headings, lists, tables, links, code and pictures.
Web page (.html)A ready-to-open web page.
Plain text (.txt)Just the words.
Good to know: Markdown cannot store colors, font sizes, fonts, alignment or rounded pictures, so those appear in PDF, Word and HTML but not in the .md file. Underline and highlight are saved as small HTML tags, which most Markdown viewers display correctly.

Questions

Is my text sent anywhere?No. Everything runs in your browser. The page only downloads its helper libraries from the internet.
Can I open a Word file?Yes. Press Open .docx / .html. Headings, lists, tables and pictures are brought in.
The selection toolbar did not appear.Select text with the mouse or by holding Shift and using the arrow keys. It only appears inside the white page.
My PDF has a long blank space or cut-off picture.Very tall pictures can split across pages. Make them smaller with the 25% or 50% buttons and download again.
